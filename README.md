# oversein.nl

Website van **Oversein**, toolkit voor noodcommunicatie zonder internet: <https://oversein.nl>

Gewone HTML en CSS zonder bouwstap, gehost met GitHub Pages. Lettertypen en afbeeldingen staan in de site zelf;
er worden geen externe bronnen, cookies of statistieken gebruikt.

- `index.html`: startpagina
- `download.html`: downloads en installatie (versie en bestandsnamen per release bijwerken)
- `404.html`: pagina niet gevonden
- `assets/`: stylesheet, Roboto (Apache-licentie 2.0, zie `assets/fonts/Roboto_LICENSE.txt`) en het logo
- `CNAME`: het eigen domein

De downloads zelf staan bij de releases van
[dares-berichtenformulier-download](https://github.com/fvanson/dares-berichtenformulier-download/releases).
